## Deviations

- `useLayoutEffect` (`Shortcut.tsx:217`) → `onBeforeMount` (`Shortcut.vue:213`). `useLayoutEffect` runs synchronously after DOM mutations in React; `onBeforeMount` runs before the first DOM paint in Vue. The Mac detection reads `navigator.userAgent` which is synchronously available, so both produce the same result. Minor timing difference: React commits the ref after layout; Vue runs before mount. No observable difference for this use case.
- React `useState(false)` (`Shortcut.tsx:95`) → Vue `ref(false)` (`Shortcut.vue:69`). Idiomatic state management translation; identical behavior.
- React `Array.isArray(children) ? children : [children]` (`Shortcut.tsx:130`) → Vue VNode walking via `collectShortcutEntries` (`Shortcut.vue:187–211`). Vue's slot API returns `VNode[]`, not `ReactNode`, so the entry collection is rewritten to handle `Text`, `Fragment`, and nested VNode types. The output is the same array of `ShortcutEntry` objects.
- `useComponentDefaults` is called (`Shortcut.vue:60`) but the `uiContext` carries no `ShortcutDefaultProps` — the function returns the original props unchanged for this component.
- Upstream `ShortcutProps` extends `ComponentPropsWithoutRef<C>` via intersection (`Shortcut.tsx:66–67`). Vue `ShortcutProps` (`dataDisplay.contracts.ts:55–80`) declares only the direct props. Extra native attributes are forwarded through `$attrs`.
