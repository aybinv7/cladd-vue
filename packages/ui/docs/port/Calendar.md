## Deviations

- `@vuepic/vue-datepicker` adapter instead of `react-day-picker` `DayPicker` — Vue `Calendar.vue:2` imports `VueDatePicker` from `@vuepic/vue-datepicker` and renders the grid via its `inline` mode with `#month-year` slot for the caption/nav. Upstream `Calendar.tsx` renders `DayPicker`. Grid DOM, classNames, and a11y attributes belong to the dependency, not to upstream code. The adapter boundary is intentional and documented here; upstream Litmus is `SIZES` and the prop contracts.
- `disabled` matcher narrowed to `boolean | ((date: Date) => boolean)` (`calendar.contracts.ts:81`, `Calendar.vue:197`). Upstream `Matcher` also covers `{before,after}`, `{from,to}`, `Date[]`, and `Matcher[]`. Vue drops those arms; the computed `isDateDisabled` and boolean `:disabled` cover the common case. Broader matcher support is a future deviation to add if needed.
- `locale` is a BCP47 string formatted with `Intl.DateTimeFormat` (`Calendar.vue:214`), not a DayPicker locale object. The caption label (`monthLabel`) uses that formatter; weekday headers are owned by the dependency and follow its own `locale` prop.
- `format` is `(value) => string` (`calendar.contracts.ts:129`), not `(value) => ReactNode`. Upstream can return elements; Vue renders `label` as text (`DatePicker.vue:103`). Returning nodes is not supported — use the `#default` slot to override the trigger label.
- `calendarProps` narrow allowlist (`calendar.contracts.ts:117`, `DatePicker.vue:199`). Upstream `DatePicker.tsx:41` types `calendarProps` as `Omit<Partial<PropsBase>, 'mode' | 'required'>` and spreads it into `Calendar`. Vue types it as `Partial<CalendarProps>` and forwards an explicit allowlist; unlisted `PropsBase` fields such as `startMonth`/`endMonth` are dropped until added.
- `header`/`footer` are Vue slots (`Calendar.vue:68`), not `ReactNode` props. `headerClassName`/`footerClassName` remain props.
- Trigger `class` via `$attrs` + `Button` — upstream `DatePicker` `className` is a trigger prop; Vue merges `attrs.class` into `rootClass` (`DatePicker.vue:139`).
