## Deviations

- `onChange` does not fire on clear. Upstream's `clear` closure is `onClear ?? (() => onChange(''))` (`SearchField.tsx:46`), which fires the `onChange` callback with `''`. Vue's `clear` handler sets `model.value = ''` and emits `'clear'` but does not emit `'change'` (`SearchField.vue:84-87`). A consumer listening only to `change` will not see the clear. `v-model` still updates via `model.value = ''`.
- `icon` slot default content renders `<SearchIcon :class="searchFieldIconClasses" />` (`SearchField.vue:148`), while upstream renders `<SearchIcon className="text-cladd-fg-softer" />` (`SearchField.tsx:66`). Same class, different mechanism (slot vs inline JSX fallback).
